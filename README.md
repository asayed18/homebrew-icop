# homebrew-icop

Homebrew tap for [icop](https://github.com/asayed18/icop), a local AI content
filter plugin for VLC on macOS (Apple Silicon and Intel, macOS 14+).

```sh
brew tap asayed18/icop
brew install --cask icop
```

Quit VLC first. The cask downloads the release archive for your Mac and runs
the `install_icop_plugin.sh` that ships inside it, which installs the plugin
into VLC.app. If macOS answers "Operation not permitted", allow your terminal
under System Settings > Privacy & Security > App Management and run
`brew reinstall --cask icop`.

- After a VLC update: `brew reinstall --cask icop` (updates replace VLC.app).
- Remove: `brew uninstall --cask icop` (removes exactly the files the release
  installed).

## How the cask is updated

`Casks/icop.rb` is generated by `scripts/render_cask.sh` and committed by the
[Update icop cask](.github/workflows/update-cask.yml) workflow, which picks the
newest published icop release that ships both macOS archives. It runs when
icop publishes a release (`icop-release` dispatch), every six hours, or
manually with an optional version.
